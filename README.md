# StudyHub — улучшенная версия

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере (Chrome, Edge, Firefox или Safari).

## Что нового
- **Светлая и тёмная тема** — переключатель внизу сайдбара, тема запоминается.
- **Улучшенные кнопки** — плавные hover/active-состояния, более аккуратные тени и варианты (основная, secondary, ghost).
- **Более приятный интерфейс** — обновлённая цветовая палитра, скругления, анимации появления экранов, шрифт Inter.
- **Профиль / «Вход через Мос.ру»** — кнопка-аватар вверху справа. Можно сохранить имя (локально). Настоящий OAuth Мос.ру требует backend и официальную регистрацию сервиса, поэтому здесь удобная симуляция.

## Как редактировать
- Весь код в одном файле `index.html` (HTML + CSS + JS).
- Можно открывать в VS Code или любом редакторе.

## Что уже работает
- Добавление предметов и дат экзаменов.
- Добавление тем, отметка выполнения и удаление.
- Автоматическая сортировка тем по датам.
- Прогресс по каждому предмету и общий процент.
- Сохранение данных и темы в `localStorage` браузера.
- Локальный профиль пользователя.

## Важно
Это frontend-версия без сервера. Данные хранятся только в текущем браузере. Для публикации можно использовать GitHub Pages.
